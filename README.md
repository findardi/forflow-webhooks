# Forflow - Webhooks as a Service

A side project built for learning: a service that delivers webhooks reliably on
behalf of other applications.

## Why

Webhooks look simple from the outside — just an HTTP POST. But doing them
reliably at scale involves queues, retry strategies, idempotency, security, and
observability. This project is my way of learning those pieces by building them.

## Tech stack

- Golang
- Bun
- Svelte
- Postgres
